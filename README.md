## Contexto e autoria

Este projeto é uma versão própria, refatorada e adaptada para portfólio, baseada em um sistema acadêmico desenvolvido em equipe durante o curso.

No projeto original, atuei como principal responsável por toda a camada de frontend, incluindo identidade visual, design system, templates Django, dashboard, landing page, páginas públicas, formulários, telas de autenticação e experiência do usuário.

Além do frontend, também contribuí diretamente em funcionalidades de backend, como autenticação, recuperação de senha, upload de mídia, rotas, seeders, estatísticas dinâmicas, filtros avançados, integração com Chart.js, geolocalização com geopy, mapas interativos com Leaflet.js e controle de acesso.

Esta versão foi criada para reorganizar, refatorar e apresentar o projeto com uma identidade própria, documentação profissional e melhorias visuais/técnicas para fins de portfólio.
